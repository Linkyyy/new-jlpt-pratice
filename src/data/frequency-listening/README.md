# 仅用于统计的听力原文

本目录收录有日文原文、尚无可用音频的用户提供题库，只供构建词频索引。它不是可作答题库，不参与首页题量、成绩、学习记录或收藏题目加载。每条来源固定 `available: false`，词频出处显示该来源，但不提供无效的作答入口。

2026-10-22 批次包含 8 个场次、236 道小题、230 段不同原文。N1／N2 每卷最后一段由两个小题共用，同卷、同字段、相同规范化原文只计算一次出现次数，覆盖题目仍包含两个小题。不同场次分别计数。

`exams/*.json` 保留原始 objectId、identity、父题 ID、源文件名与 SHA-256 校验值；日本语正文使用 `subtitle` 字段，小题没有独立原文时继承父题。只导入日文原文和题目选项，不导入中文译文、答案、AI 音频提示或原音频引用；也不生成代用音频。

```sh
npm run import:listening-transcripts -- --source "整卷 JSON 目录"
npm run build:frequency
npm run test:listening-transcripts
```

导入器复用整卷校验，统计来源独立、可增量合并，重复导入保持 ID 和内容不变。`index.json` 记录场次及原文数量；构建指纹包含索引和全部原文文件，更新后自动重建词频。来源目录不会被浏览器批量下载，部署查询只读取已有压缩统计索引。

当前只开放统计。以后若补齐音频并开放作答，需要正式迁入作答题库并处理统计来源重复，不能仅把这些记录的 `available` 改为 `true`。
