# N1–N3 文章译文

每个等级的 `*-index.json` 把题目 ID 指向同等级 `*.zh.json` 中的文章位置。同篇小题共用一份译文。每篇文章按原文顺序保存日中段落，独立的题组编号与其后的首段一起展示。

译文优先采用题库中与原文段落对应的中文，补译缺少译文的段落，并保留文章语法的空格编号。图片文字完整且已校对的文章标有 `transcribedImage`，以便界面注明日文来源。目前仍有 28 篇 N1、28 篇 N2 和 25 篇 N3 图片文章等待完整转录。

练习提交后，N1 在句尾、N2 和 N3 在段尾显示「译」按钮，点开后在原文下方显示译文。服务端用同一份译文对齐句界，并把日中句界无法清楚对应的连续句子合在一起。图片中的表格和清单在原图下方按转录的小节展示。

调整译文或题库后，可运行 `node --test scripts/test-passage-translations.mjs` 核对题目关联及原文顺序。
