## 重复应用与重新导入

```sh
node scripts/apply-listening-answers.mjs
npm run check:bank
npm run build:frequency
```

重新导入听力题会保留已核对答案、推导解析及来源标记；原始题库后续提供的明确答案优先。原文或选项改变时，摘要校验阻止直接复用旧推导。

已有做题记录继续保留创建时的答案及评分快照；补充答案不会改写历史成绩。重新开始的练习使用新答案。词频只统计标记为听力原文的日文部分，新增解析不会重复进入词频。
