# 词条重复复核

本次重新生成完整词频索引，合并 **151 组** 同词不同词性记录，减少 **152 条** 重复展示。词条总数由 14,978 变为 14,826；8,759 道来源题目未修改。

- 「安静／あんせい」原来的名词 3 次、形容词 2 次合为 1 条，共 5 次；两种词性、释义、原题出处均保留。覆盖题目／场次按集合去重，不能把同一道题算两次。
- 同写法、同读音的名词／形容动词可属于一个词条；合并后同时显示“名词 / 形容词”。其他词性组合要求明确的词典词头依据，不能仅凭同音就合并。
- 假名词头需检查词典对应的汉字是否唯一；「さかん」的「左官」与「盛ん」不能因为读音相同而合并。「はく」等动词／名词同形情况保留；不同读音、单词与语法／惯用句类别也保持独立。
- 词性筛选对合并词条按多词性匹配；选任一已有词性都能找到这一词条，次数显示其合并后的总出现次数。PDF／Excel 与网页一致。
- 旧收藏中的词性标识、原有假名别名继续解析至合并词条，避免索引重建使原题链接失效；不改写用户已保存的学习状态。

实现为构建期的 `mergeFrequencyDuplicateWords`，每次更新题库都会重新执行。完整合并清单和保留待确认项见 [`quality-report.json`](../src/data/bank-frequency/quality-report.json) 的 `duplicates` 字段；合并不作为词汇分级依据，没有恢复任何按真题出现等级推测的“暂定”等级。

回归验证：`node --test scripts/test-frequency-duplicates.mjs scripts/test-bank-frequency.mjs scripts/test-frequency-export.mjs`。
