# 常用汉字词头复核（2026-10-22）

本次修改 **317 个**原先以假名展示的词头，其中 **274 个**与已存在的同词汉字记录合并，**43 个**仅调整词头显示。总词条数从 **14,648** 变为 **14,374**。

例如：`あきらめる → 諦める`、`さまざま → 様々`、`まんが → 漫画`、`こころ → 心`、`なつかしい → 懐かしい`。

处理范围与验证：

- 显式复核清单基于固定版本 JMdict 的完整词条关系、读音、词性与现代常见表记；不是将所有假名按同音批量换成汉字，也不宣称测量了全日语文本的使用比例。
- 原假名及旧写法仍可检索；旧收藏的语义标识仍能找到合并后的词条。读音、词性、中文义项、原题出处继续保留。
- 原题题干、选项、答案不改写。8,759 道题、94 个场次、37,925 个文本单元和 354,705 次总出现次数保持一致。覆盖原题／场次去重，出现次数相加。
- 逐一对比全部原词条的去向：原有参考等级完整保留；显示词头没有在原文出现时，不凭新显示的汉字表记套用额外等级。合并前不同公开来源给出的等级及证据均保留。
- 「しっかり」「きっかけ」等通常使用假名的词继续以假名显示；「ジム／事務」「テンポ／店舗」「リネン／理念」等同音异义的片假名词不转换。混合多个汉字词义的「つく」「とる」「かく」等也不强选单一汉字。

可复现的显式清单、JMdict id 和固定来源见 [`preferred-headwords.json`](../src/data/frequency-levels/preferred-headwords.json)。构建结果详见 `quality-report.json` 中的 `headwords`、`headwordDuplicates`。
