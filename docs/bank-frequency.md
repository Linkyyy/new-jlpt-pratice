# 题库词频统计

页面 `/frequency`，首页底部“学习工具 · 题库词频统计”提供入口。普通浏览不要求云备份登录。

## 筛选与查看

提供单词、语法表达、惯用句三个榜单，接续表达合并到“单词”，以“词性 → 接续词”筛选（旧 `kind=connective` 链接会转换为该筛选）。可组合筛选题库来源、等级、场次、主/子题型、文本范围、词性、最少出现次数，并按出现次数（多到少 / 少到多）、覆盖题目、覆盖场次或五十音排序。搜索支持词形和读音（平/片假名归一），结果分页；点击词条查看中文释义、语法用法和全部出处，可按试卷筛选、分页查看，并预览题干、选项及相关文章/听力原文摘录；链接到现有练习页。缺资源的题保留统计但不提供无效练习入口。手机端筛选默认收起，点击“筛选与排序”展开；桌面直接显示。筛选保存到 URL，可刷新、分享并使用浏览器前进/后退；不写个人设置或云备份。

子题型遵循官方分类，定义及等级适用范围见 `frequency-subtypes.mjs`：词汇分汉字读音、表记、词语构成、文脉规定、近义替换、用法；语法分句子语法1（语法形式判断）、句子语法2（句子组合）、文章语法；阅读分短篇／中篇／长篇内容理解、综合理解、主张理解（长篇）、信息检索；听力分课题理解、要点理解、概要理解、发话表现、即时应答、综合理解。各等级只显示适用项，N2 的词语构成与文脉规定单独统计。根据说明语义及当前 2010 年后格式的分等级题号对应关系判断，原创或无法确认的题显式显示“未分类”，不把原题号当官方类型名。

中文词典为有固定校验值和明确归属的本地数据，语法／接续词／惯用句学习说明覆盖当前表达清单；每条返回释义、用法及来源。常见词、礼貌表达及常见活用另有逐条编写的站内学习释义，按词头和读音严格匹配补足缺项；兼容旧词典的日文词性标记、多读音以及源明确给出的中文异体词释义。无法确认的词不推测翻译，显示“释义待补充”。详见 [词典来源与维护](../src/data/frequency-dictionary/README.md)。释义不因界面语言改变；日语／英文界面仍可看中文释义，字段标题本地化。

## 统计口径

### 等级独有范围

筛选新增 `exclusive=all|N1|N2|N3|N4`（默认 `all`）：

- N1 独有：仅纳入 N1 题目，排除在 N2–N5 任一题目中出现的同一词条。
- N2 及以上独有：纳入 N1、N2，排除在 N3–N5 出现的词条；N1、N2 互相共有的词保留。
- N3 / N4 及以上依此类推。可再用“日语等级”只查看范围内某一级的频次。

低等级对照始终覆盖全部题库来源、年份、题型、子题型、文本字段及缺资源但有文字的题目，不受当前筛选、最少次数、词性或搜索限制。同一词条的不同词性共享排除结果，活用按既有基本形合并；接续词并入单词对照，语法表达和惯用句分别独立对照。出现一次就排除，单个实例按已加载索引缓存等级出现位图，不请求外部词典或数据库。

这是当前题库的文本差集，**不代表官方 N1 / N2 词汇分级**；语义、词形变体及缺失文本会影响结果。页面、出处和 Excel/PDF 导出沿用相同差集，导出注明范围与全库对照口径。筛选保存到 URL；切换范围时自动清除冲突的低等级/子题型，API 对手动输入的冲突参数返回 400。

### 文本统计

- 全部导入题库（包括 unavailable 中仍有原始文本的题目）及原创模拟题。当前 8669 道导入题 + 90 道原创题。
- 题文包括文章、题干、各个选项和明确标识的日文听力原文。排除题型说明、中文解释与翻译、HTML 标签及 ruby 注音、对话的男/女说话人标签；不执行来源 HTML。
- 不做图片 OCR、MP3 转写或外部模型推断。无法识别听力原文时，仅统计已有的题干和选项，不填造原文。重复附在译文之后的原文不再次计入。
- 共享文章按题库来源、等级、年月、题型、文本字段和规范化文本去重；一篇文章对应多个小题时，出现次数计一次，覆盖题目包含这些小题。不同场次的重复文章独立计数。
- 题干与文章相同视为继承重复；每个选项仍是独立文本，不拼接排序题选项推测完整句子。所有干扰项也在统计范围内，因此频次不等于正确答案或真实考查频率。
- 单词使用 Kuromoji 0.1.2 / IPADIC 分词，归并基本形，并用基本形取得读音。保留名词、动词、形容词、副词、连体词、接续词，排除数字、代名词、非自立词、接尾词和常见停用词。不是对题库内每个字符或所有可能词组的穷举。
- 语法榜使用 `frequency-lexicon.mjs` 中的常见固定表达/活用变体清单，进行词边界匹配。同类重叠取较长表达。接续词结合接続詞词性和固定接续表达，对 `では`、`でも` 等再检查词性/句首位置。语义歧义和漏计仍可能存在，页面标注为文本表达频次，不称完整知识点识别或官方大纲覆盖。「にもかかわらず」（尽管）与「にかかわらず」（不论）分别统计。
- 惯用句榜按 `frequency-idioms.mjs` 的 114 条常见表达及异体写法匹配，只显示题库实际出现的词条。按连续的完整分词基本形匹配，归并「気に入った／気に入ります」等活用和「気が付く／気がつく」等表记；兼容活用导致的分词边界变化。同处重叠取最长项，不跳过词语、标点或段落，也不拼接不同选项。它不是任意搭配或全部惯用句的穷举；字面义与惯用义需结合原题判断。各词附本项目编写的中文含义和用法，可用全部现有筛选、等级差集、出处预览及 Excel/PDF 导出。
- 排除“听力第……题”“请选择第……题”等中文占位题干，避免当成日语词汇；不修改题库原始内容。
- 覆盖场次按题库来源 + 等级 + 年月计算；同一场次的不同大题不重复计场次。

## 构建与部署

```bash
npm run build:frequency
npm run test:frequency
npm run build
```

Kuromoji 仅为开发/构建依赖；其词典不发送给浏览器，也不用于在线 API 的逐次分词。

构建前计算原始题库、分析代码、表达词典和生成脚本的指纹。输入未变化时直接复用；重新导入题库或修改规则后，下次构建自动更新。

产物：

- `src/data/bank-frequency/manifest.json`：轻量目录、子题型和汇总，供页面筛选使用。
- `src/data/bank-frequency/corpus.json.gz`：题目元数据、词条和压缩出现索引，供服务端使用。保留 ID，不保存题目答案或完整文章。

`next.config.ts` 将压缩索引追踪到 `/api/frequency` 的生产函数。`bank-frequency.server.ts` 在每个服务端实例首次读取/解压一次；后续复用。浏览器仅接收当前页榜单与按需请求的出处，不接收整个索引。

## API 与成本范围

`GET /api/frequency` 接受与页面相同的 URL 参数：`source`、`level`、`exclusive`、`period`、`category`、`subtype`、`field`、`kind`、`pos`、`order`、`min`、`q`、`page`、`size`，可选 `term` 读取某个词条的出处，使用 `examplePage`、`exampleSize`（1–50）、`examplePaper` 分页和按试卷筛选。

输入限制：搜索不超过 80 字、URL 查询不超过 2000 字符、每页最多 100 条、出处每页最多 50 题，拒绝不存在的等级/场次/子题型以及主子题型冲突。无结果返回正常空榜单，参数错误返回 400，服务失败返回可重试错误。

接口使用现有实例内限流（60 次/分钟/IP），成功响应允许浏览器/共享缓存短时缓存。此页面不调用 D1、R2、外部 AI 或分词服务；会产生正常 Vercel 页面/函数请求，实例限流不是跨实例的全站费用上限。筛选与分页不修改个人做题记录。

## 验证

`test-bank-frequency.mjs` 使用真实分词器验证词形与读音、文章去重和覆盖数、文本范围、排序题不拼接、最长表达、惯用句活用与异体归并、连续词边界与分词变化、接续词歧义、复合筛选、排序分页、输入边界，以及正式索引的全量 ID/出现记录完整性。


## Excel / PDF 导出

排名区提供与“出现次数”同样风格的无边框“导出”入口，点击后在浮窗中选择 Excel / PDF，将**当前筛选、搜索、最少次数和排序后的全部结果**导出，而非仅导出当前分页。不导出个人收藏、账号或学习记录，也不自动改变筛选。导出过程中提供 loading 状态和失败重试提示。

- Excel 为真实 `.xlsx` 文件，含频率排名和查询说明两张表；保留原统计列，并新增中文释义、用法／接续、释义来源三列。次数/排名为数值，首行冻结并开启筛选，释义自动换行。词条按文本单元格写入，不将以 `=` 开头的内容解释为公式。
- PDF 为直接下载的 A4 文件，保留日文词条与读音、统计列、筛选条件、页码及重复列头；逐条显示中文释义、词性、语法用法和出处许可。使用服务端 Noto Sans CJK JP 字体，字体仅包含在导出函数中，不发送到普通浏览页面；许可证位于 `src/data/export-fonts/LICENSE.txt`。
- `GET /api/frequency/export` 接受相同筛选参数，增加 `format=xlsx|pdf` 和 `locale=zh|ja|en`；分页参数不会截断导出内容。无结果时生成空表/说明，参数错误返回 400。
- 导出接口复用 IP 实例限流（6 次/分钟），每个实例一次只处理一个导出，最多支持 25,000 行（当前全库约 17,000 词条）。超出明确返回错误，不悄悄截断。不同实例的限制不构成全局费用硬上限。
- 导出不调用 D1、R2、外部模型或实时分词。大型 PDF 会包含较多页，可先筛选需要的范围。含中文释义的约 1.7 万个单词已验证 Excel/PDF 全量生成；PDF 逐条显示释义和用法，页数会多于原先仅有统计列的版本。

新增验证：`node --test scripts/test-frequency-export.mjs` 检查 XLSX 的行数、类型、语言与查询说明、公式型字符串安全及 PDF 的嵌入字体/Unicode 映射；词频测试补充全部出处分页、分卷查看和双向排序。


## 排序与词汇参考等级

排序按钮跟随“排序方式”展示当前指标，支持出现次数、覆盖题目、覆盖场次及五十音的正序／倒序，点击按钮只反转当前指标。PC 表格将当前指标移到第一列并标注排序方向，手机列表优先突出同一指标。

新增“词条参考等级”筛选 N1–N5，包含公开参考词表分级且在真题中出现的词；“试卷等级”独立筛选，因此能查看参考 N2 词在 N1 真题的出处。选择参考等级自动切换到用户提供真题题库，并清除差集条件。词条、出处详情、Excel 和 PDF 显示参考等级；未收录词不推测等级。来源与许可见 [参考词表说明](../src/data/frequency-levels/README.md)。

## 分词质量与简体释义

未知假名连写、以小假名开头的残片及明确的听力选项占位文本不进入单词榜；未知词若能在词典或参考词表中完整核实则保留。语法清单里的「っぽい」「っぱなし」等完整表达仍参与语法统计。规则只影响派生索引，不改变题库原文、答案或原题链接；构建摘要中的 `excludedFragments` 记录排除的 token 次数（不是删题数）。分词仍可能有歧义，原题出处用于核对。

OpenCC 在构建时将中文释义和用法转为简体；日语词条、词典链接目标及带假名的引号内例句保持原样。转换后的同一份释义用于页面、Excel、PDF，无运行时转换或外部请求。

## 词表质量复核与完整表达分级

构建时先生成释义，再复核派生单词索引：

- 删除符号拼接、占位文字、开头缺字的长音片段。
- 未收录可信释义，且词典与参考词表都无法核实完整表记的词，排除为 `unverified_word_or_spelling`，其中包含错拼和分词残片。不会把相似词的翻译或等级贴过来。
- 分词标为人名／组织名的条目不作为学习词条保留，参考词表明确收录的词和站内已核实的学习词条除外。已核实的普通词、常见地名、Tシャツ 等混合表记保留。
- 缺少中文释义不等于错误。能核实表记但释义尚未覆盖的词保留“释义待补充”。

删除仅作用于排名、搜索和导出使用的索引，不改原题、选项、答案或学习记录。词条编号和 postings 一起重映射，保持所有保留词的次数与原题引用正确。可审计的 [quality-report.json](../src/data/bank-frequency/quality-report.json) 记录每个排除条目的原因、次数与最多 3 个原题编号。每次构建重新生成，后续可据出处复核并恢复。

“词条参考等级”同时支持单词、语法、惯用句及“未分级”。语法采用额外的公开社区资料，惯用句只匹配完整表达；未确认等级的表达可单独筛选，绝不依据组成词或试卷等级推断。来源及限制见 [分级说明](../src/data/frequency-levels/README.md)。所有等级都是非官方学习参考。

手机列表左侧为排名，右侧为当前排序指标及数值；选择五十音排序时左侧仍保留排名。电脑表格保留当前排序指标优先列，避免更改先前的桌面排序布局。

复核同时修正了 12 处有词典证据的分词读音错误（例如「厳密」误分为「いむひそか」、「図形」误读为「づけい」），报告中的 `correctedReadings` 保留原读音、新读音与来源。只匹配明确复核过的错误读音；合法的其他读法不自动覆盖。人名与参考词表的豁免还必须同时匹配表记和读音，避免把同字人名当成参考词汇。

### 复合词与补充分级

词性菜单新增“复合词”，实际词性仍保留为名词或动词；筛选、词条详情、Excel 和 PDF 使用同一标记。通过词典可核对的复合动词、复合名词、名词化形式及明确构词关系识别，不把任意两个汉字或相邻词自动认定为复合词。分词器拆开的复合名词只有整词也在可信词典中时才补充为词条，起止位置必须与原题词边界一致，不跨句、跨选项拼接。复合词和组成词是不同检索词条，出现次数不能相加后当作原文总词数。

惯用句重新扫描覆盖惯用句、固定表达、常用搭配与部分四字熟语。候选发现来自 JMdict expression 数据与原题语境；中文学习释义及用法为站内整理，不直接批量收录全部候选。最终仍按完整表达、词形变化和边界匹配，共享文章/听力原文去重。

参考等级使用原有资料、补充词表、同读音的整词写法核对，以及有明确标识的站内估级。站内估级在页面、PDF、Excel 均标明；原有来源等级优先保留。所有等级均非 JLPT 官方大纲，词条等级与试卷等级分别筛选。逐项报告见 `src/data/bank-frequency/level-review-report.json`，来源、限制和复现步骤见 [分级说明](../src/data/frequency-levels/README.md)。
