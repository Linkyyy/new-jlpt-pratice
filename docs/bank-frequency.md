# 题库词频统计

页面 `/frequency`，首页底部“学习工具 · 题库词频统计”提供入口。普通浏览不要求云备份登录。

## 筛选与查看

提供单词、语法表达、接续表达三个榜单，可组合筛选题库来源、等级、场次、主/子题型、文本范围、词性、最少出现次数，并按出现次数（多到少 / 少到多）、覆盖题目、覆盖场次或五十音排序。搜索支持词形和读音（平/片假名归一），结果分页；点击词条查看全部出处，可按试卷筛选、分页查看，并预览题干、选项及相关文章/听力原文摘录；链接到现有练习页。缺资源的题保留统计但不提供无效练习入口。手机端筛选默认收起，点击“筛选与排序”展开；桌面直接显示。筛选保存到 URL，可刷新、分享并使用浏览器前进/后退；不写个人设置或云备份。

## 统计口径

### 等级独有范围

筛选新增 `exclusive=all|N1|N2|N3|N4`（默认 `all`）：

- N1 独有：仅纳入 N1 题目，排除在 N2–N5 任一题目中出现的同一词条。
- N2 及以上独有：纳入 N1、N2，排除在 N3–N5 出现的词条；N1、N2 互相共有的词保留。
- N3 / N4 及以上依此类推。可再用“日语等级”只查看范围内某一级的频次。

低等级对照始终覆盖全部题库来源、年份、题型、子题型、文本字段及缺资源但有文字的题目，不受当前筛选、最少次数、词性或搜索限制。同一词条的不同词性共享排除结果，活用按既有基本形合并；单词、语法表达、接续表达各自对照。出现一次就排除，单个实例按已加载索引缓存等级出现位图，不请求外部词典或数据库。

这是当前题库的文本差集，**不代表官方 N1 / N2 词汇分级**；语义、词形变体及缺失文本会影响结果。页面、出处和 Excel/PDF 导出沿用相同差集，导出注明范围与全库对照口径。筛选保存到 URL；切换范围时自动清除冲突的低等级/子题型，API 对手动输入的冲突参数返回 400。

### 文本统计

- 全部导入题库（包括 unavailable 中仍有原始文本的题目）及原创模拟题。当前 8669 道导入题 + 90 道原创题。
- 题文包括文章、题干、各个选项和明确标识的日文听力原文。排除题型说明、中文解释与翻译、HTML 标签及 ruby 注音、对话的男/女说话人标签；不执行来源 HTML。
- 不做图片 OCR、MP3 转写或外部模型推断。无法识别听力原文时，仅统计已有的题干和选项，不填造原文。重复附在译文之后的原文不再次计入。
- 共享文章按题库来源、等级、年月、题型、文本字段和规范化文本去重；一篇文章对应多个小题时，出现次数计一次，覆盖题目包含这些小题。不同场次的重复文章独立计数。
- 题干与文章相同视为继承重复；每个选项仍是独立文本，不拼接排序题选项推测完整句子。所有干扰项也在统计范围内，因此频次不等于正确答案或真实考查频率。
- 单词使用 Kuromoji 0.1.2 / IPADIC 分词，归并基本形，并用基本形取得读音。只保留名词、动词、形容词、副词、连体词，排除数字、代名词、非自立词、接尾词和常见停用词。不是对题库内每个字符或所有可能词组的穷举。
- 语法榜使用 `frequency-lexicon.mjs` 中的常见固定表达/活用变体清单，进行词边界匹配。同类重叠取较长表达。接续榜结合接続詞词性和固定接续表达，对 `では`、`でも` 等再检查词性/句首位置。语义歧义和漏计仍可能存在，页面标注为文本表达频次，不称完整知识点识别或官方大纲覆盖。
- 语法选择、语句排序和文章语法按说明语义识别，不依赖不同等级变化的问题序号。词汇填空、阅读和听力未能确定语义子类时，保留等级与实际问题编号，不凭序号臆造官方子题型名。
- 覆盖场次按题库来源 + 等级 + 年月计算；同一场次的不同大题不重复计场次。

## 构建与部署

```bash
npm run build:frequency
npm run test:frequency
npm run build
```

Kuromoji 仅为开发/构建依赖；其词典不发送给浏览器，也不用于在线 API 的逐次分词。

构建前计算原始题库、分析代码、表达词典和生成脚本的指纹。输入未变化时直接复用；重新导入题库或修改规则后，下次构建自动更新。

产物：

- `src/data/bank-frequency/manifest.json`：轻量目录、子题型和汇总，供页面筛选使用。
- `src/data/bank-frequency/corpus.json.gz`：题目元数据、词条和压缩出现索引，供服务端使用。保留 ID，不保存题目答案或完整文章。

`next.config.ts` 将压缩索引追踪到 `/api/frequency` 的生产函数。`bank-frequency.server.ts` 在每个服务端实例首次读取/解压一次；后续复用。浏览器仅接收当前页榜单与按需请求的出处，不接收整个索引。

## API 与成本范围

`GET /api/frequency` 接受与页面相同的 URL 参数：`source`、`level`、`exclusive`、`period`、`category`、`subtype`、`field`、`kind`、`pos`、`order`、`min`、`q`、`page`、`size`，可选 `term` 读取某个词条的出处，使用 `examplePage`、`exampleSize`（1–50）、`examplePaper` 分页和按试卷筛选。

输入限制：搜索不超过 80 字、URL 查询不超过 2000 字符、每页最多 100 条、出处每页最多 50 题，拒绝不存在的等级/场次/子题型以及主子题型冲突。无结果返回正常空榜单，参数错误返回 400，服务失败返回可重试错误。

接口使用现有实例内限流（60 次/分钟/IP），成功响应允许浏览器/共享缓存短时缓存。此页面不调用 D1、R2、外部 AI 或分词服务；会产生正常 Vercel 页面/函数请求，实例限流不是跨实例的全站费用上限。筛选与分页不修改个人做题记录。

## 验证

`test-bank-frequency.mjs` 使用真实分词器验证词形与读音、文章去重和覆盖数、文本范围、排序题不拼接、最长表达、接续词歧义、复合筛选、排序分页、输入边界，以及正式索引的全量 ID/出现记录完整性。


## Excel / PDF 导出

排名区提供 Excel / PDF 按钮，将**当前筛选、搜索、最少次数和排序后的全部结果**导出，而非仅导出当前分页。不导出个人收藏、账号或学习记录，也不自动改变筛选。导出过程中提供 loading 状态和失败重试提示。

- Excel 为真实 `.xlsx` 文件，含频率排名和查询说明两张表；次数/排名为数值，首行冻结并开启筛选。词条按文本单元格写入，不将以 `=` 开头的内容解释为公式。
- PDF 为直接下载的 A4 文件，保留日文词条与读音、统计列、筛选条件、页码及重复列头。使用服务端 Noto Sans CJK JP 字体，字体仅包含在导出函数中，不发送到普通浏览页面；许可证位于 `src/data/export-fonts/LICENSE.txt`。
- `GET /api/frequency/export` 接受相同筛选参数，增加 `format=xlsx|pdf` 和 `locale=zh|ja|en`；分页参数不会截断导出内容。无结果时生成空表/说明，参数错误返回 400。
- 导出接口复用 IP 实例限流（6 次/分钟），每个实例一次只处理一个导出，最多支持 25,000 行（当前全库约 17,000 词条）。超出明确返回错误，不悄悄截断。不同实例的限制不构成全局费用硬上限。
- 导出不调用 D1、R2、外部模型或实时分词。大型 PDF 会包含较多页，可先筛选需要的范围。现有库约 16,664 个单词导出已验证 Excel/PDF 全量生成。

新增验证：`node --test scripts/test-frequency-export.mjs` 检查 XLSX 的行数、类型、语言与查询说明、公式型字符串安全及 PDF 的嵌入字体/Unicode 映射；词频测试补充全部出处分页、分卷查看和双向排序。
