# 题库问题反馈

练习设置中的「反馈题目问题」允许选择答案、文字、图片、音频或其他问题，并填写 5–2000 字说明。服务端根据真实题目 ID 查询题库，自动保存年份、等级、题型、原题号；不会相信客户端伪造的题目元数据。反馈不包含密码、会话令牌、原始 IP、整份答案或学习记录。请勿在说明中填写私人资料。

## 首次启用

1. 继续使用云备份的 `CLOUDFLARE_ACCOUNT_ID`、`CLOUDFLARE_D1_DATABASE_ID` 和 `CLOUDFLARE_D1_API_TOKEN`，不新增数据库或第三方服务。
2. 在 Cloudflare D1 控制台执行 [0002-question-feedback.sql](../migrations/0002-question-feedback.sql)，或在仓库配置 `.env.local` 后运行：

   ```sh
   node --env-file-if-exists=.env.local scripts/setup-question-feedback.mjs
   ```

   脚本只创建反馈表和索引，可以重复执行，不会删除原有云备份。应用运行时不会静默创建或修改生产数据库结构。
3. 在 Vercel 项目环境变量中设置 `FEEDBACK_ADMIN_USERS` 为已有云备份账号的用户名。多个管理员使用英文逗号分隔，例如 `owner,editor_1`，不填写密码。用户名会转为小写。未设置时，所有账号均无法读取反馈列表。
4. 重新部署。在 `/feedback` 点击云备份图标，登录允许名单中的账号后会自动刷新列表，也可手动点击「刷新」。普通用户及未登录访客无法读取或修改反馈。

数据库或表未就绪时，提交会明确报错，不会显示虚假的提交成功。

## 查看与处理

- 管理页：`https://你的域名/feedback`。
- 按待处理、处理中、已处理筛选；每次最多加载 50 条，支持继续加载。
- 可在新标签页打开原题，核对后修改处理状态。这里只保存处理状态，不会直接更改题库答案或资源。
- 页面和 API 均不缓存私人反馈；禁止匿名读取；状态更新校验同源与管理员会话。
- 在管理页登录、退出或发现账号会话变化时会清空并重读列表；旧的异步响应不能重新填回已清空的私密反馈。

## 请求限制

反馈提交同时使用实例内突发限制与 D1 持久限流：同一 IP 每小时最多 10 次提交，登录账号每小时另限 20 次。IP 仅用于生成散列限流键，不保存到反馈记录；来自不可信代理的 IP 请求头不会被信任。数据库查询为参数化语句，说明以纯文本显示，限制实际请求大小 8 KiB。

测试：`node --test scripts/test-question-feedback.mjs`。测试使用内存 SQLite 和模拟 Cloudflare 请求，不会操作生产数据库。

词条纠错同样出现在本页管理列表，显示词形、读音、词性及具体问题类型，并链接回词频统计。后端通过 `frequency:` 标记和结构化快照复用原表，不需要新建表；普通题目反馈格式和处理权限不变。详情见 [词频功能说明](bank-frequency.md#词条收藏复习与纠错)。
