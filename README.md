# JLPT Practice

日语能力考试练习应用，使用 Next.js 16.4、React 19 和 TypeScript。支持分级练习、模拟考试和本地收藏。

## 本地运行

```bash
npm ci
npm run dev
```

打开 http://localhost:3000。收藏与学习记录保存在当前浏览器的 localStorage 中。

## 外观与语言

首页提供“外观与语言”设置，可选日间、夜间护眼或跟随系统，以及中文、日本語、English。偏好保存在 `jlpt-practice.display.v1`，刷新及同浏览器的其他标签页会同步；切换不改变题目、原有解析、收藏夹名称或已保存答案。用户自行命名的收藏夹保持原名。题库原文不做机器翻译。

夜间主题使用柔和的深色背景，覆盖题目、答题卡、播放器、设置及确认弹窗；跟随系统会响应系统明暗变化，手动选择优先。页面首次绘制前应用保存的主题，避免深色偏好下出现白色闪屏。界面译文集中在 `src/lib/i18n/messages.ts`，主题色在 `src/app/themes.css`；相关检查为 `node --test scripts/test-display.mjs`。

## 学习记录与首页

收藏页 `/favorites` 现在包含收藏、错题本和待复习三种视图。错题从已提交历史作答自动汇总，不会自动加入收藏夹；显示累计错误次数，可按错误次数、复习时间或最近作答排序。`/favorites?view=mistakes` 和 `/favorites?view=due` 可直接打开对应视图，支持练习未收藏的错题，并保留完整的作答与复习流程。

收藏设置中的“批量整理收藏”可按年份、题号、题干关键词搜索，限定收藏夹并全选当前结果，批量加入或移出目标收藏夹。加入保留其他归属，移出后无归属的题目回到默认收藏夹；取消收藏须再次确认，做题记录与错题记录保留。批量操作一次保存，不改变原收藏时间，整理结果随现有云备份一起保存。

首页的“继续学习与复习”卡片同时提供上次未完成练习、到期错题和薄弱题型建议。答错后次日复习，连续答对后逐步延长到3、7、14、30、60天；这是基于作答表现的复习建议。学习记录页加入本周/上周周报，按日本时间周一划分，展示已提交作答、正确率、完成次数、学习天数与题型表现。新记录保存可选的逐题提交时间，旧记录沿用原完成/保存时间估算，不改写原答案；旧备份仍可恢复，未交卷考试不提前判定或纳入错题。

首页保留选择练习、续做与最近记录；统计（已练题目、完成次数、正确率、连续学习天数）集中在学习记录页。上方“继续上次”固定恢复最近未完成记录的试卷、答案、位置及字号，并显示已提交/已选择题量。选择区域的“开始新练习”或“进入考试准备”始终创建独立记录，原记录保留。按钮下方的“本卷练习记录”展示所选试卷累计去重已练题数、完成次数与最佳成绩，与本次作答进度分开。答题卡中的小圆点表示曾练习，当前轮次仍按原有颜色表示正误。

练习选项、整篇提交结果与考试进度自动保存；考试使用绝对截止时间，离开、刷新后仍计时，恢复已到期考试会自动交卷。交卷记录锁定，可从学习记录进入复习并返回结算；重新作答不覆盖原答案。成绩统一使用站内练习权重：词汇 30、语法 30、阅读 60、听力 60，整卷满分 180；不等同于官方量尺分。已有记录按保存的题目快照和答案重新估分，不修改原作答或备份格式。

`/history` 支持筛选、查看每次作答。收藏页和学习记录页仅保留云备份按钮：登录账号后，可保存全部收藏夹、多夹归属和完整做题记录，并在其他设备导入。恢复时合并已有记录，保留本地已完成成绩；同名收藏夹合并，ID 冲突的不同收藏夹会重新分配 ID，多夹归属取并集。导入前校验完整数据，写入失败时回退已写入的部分并提示错误。

云备份弹窗最底部、“退出账号”右侧提供与退出账号同字号、同点击高度的柔和红色文字“清空记录”，学习记录顶栏不再显示删除入口。清空全部须再次确认，不支持单条删除，本地操作及云端 API 均拒绝按记录 ID 删除。已登录云备份账号时，同时清空该账号云备份中的全部做题记录，保留两端各自的收藏和收藏夹；清空全部也会清除学习足迹与学习天数。未登录只清空当前浏览器记录。取消或完成清空后返回备份弹窗并刷新备份版本。云端失败或备份版本冲突时保留本地记录；本地写入失败会提示实际完成情况。

做题记录使用 `jlpt-practice.study.v1`，收藏独立存储在 `jlpt-practice.favorites.v1`；云端手动备份可通过收藏页或学习记录页的云朵按钮登录使用。清理浏览器数据、无痕窗口关闭后本地记录可能丢失，请先备份到云端。学习日期使用日本时间。题库更新导致题目或答案变化时，会保留原题目及答案快照并拒绝按新题库恢复旧卷，避免用新题库重新判断历史正误。

记录与收藏备份、合并、计分和故障回退测试：`node --test scripts/test-study-store.mjs scripts/test-learning-backup.mjs scripts/test-favorites-store.mjs`。

## 整卷与成绩报告

结算报告新增细题型分析，展示每类正确率、答对/答错/未答数量、优先复习建议、回顾本卷错题和同类练习入口；没有题型说明的原创题按已有类别统计，不臆造官方题型或量尺分。

用户提供题库的整卷按词汇、语法、阅读、听力的顺序加载全部可作答题，媒体按当前题目按需加载。例如 N2 2024 年 12 月为 101 题（词汇 30、语法 21、阅读 20、听力 30），已开放原先缺图片的最后两道阅读题。已保存的旧 99/69 题整卷及 18 题阅读卷仍按原题目快照续做/复习，不自动追加题目或更改考试截止时间；重新练习时使用新版试卷。

报告、历史列表、作答详情及首页最佳成绩统一显示 `得分/满分`，例如词汇 `25/30`、阅读 `50/60`、整卷 `160/180`。报告放大得分，增加按得分区间变化的图标与鼓励语。正确率仍按答对题数/总题数计算，与加权分数分别展示。

| 练习范围 | 满分与分区 |
| --- | --- |
| 词汇 | 30 |
| 语法 | 30 |
| 词汇＋语法 | 60 |
| 阅读 | 60 |
| 听力 | 60 |
| 全级别整卷 | 语言知识（词汇30＋语法30）60 + 阅读60 + 听力60 = 180 |
| 混合及收藏练习 | 按包含的题型累计满分，例如词汇＋阅读90、阅读＋听力120、四型180 |

每个题型先按答对比例乘以该题型满分、四舍五入，再合并得到分区和总分，未作答不计分；不同题型的题数不会改变权重。单项、组合、收藏和整卷复用同一算法，词汇与语法的独立得分相加即语言知识得分。官方没有单独公布词汇、语法各占多少分，30＋30 是本站采用的练习拆分；各级别统一使用上述三分区估分，N4/N5 也不会把阅读与语言知识的题数混合加权。JLPT 官方采用量尺评分，无法仅凭答对数复现，因此站点明确标注“练习估分”，不做官方合格判定。官方分区说明见 [JLPT 成绩说明](https://www.jlpt.jp/e/guideline/results.html)。

原创精简题库目前没有听力，旧文字整卷也未覆盖听力。这些记录会标注估分不完整，整卷仍保留 180 分上限；缺少任意题型不把其分值分配给其他题型。完全未覆盖的分区显示“— / 满分”，不额外补分，也不虚构音频或题目。收藏练习只累计本次包含题型的满分，仍标注为收藏练习，不将任意题目集合称为完整试卷。

验证：`node --test scripts/test-practice-scoring.mjs scripts/test-practice-papers.mjs scripts/test-restore-practice-paper.mjs scripts/test-study-store.mjs`。

## 阅读题图片

原先因缺图排除的 84 个阅读组末尾共 168 题已开放，沿用题库中的 `pic/原文件名.jpg`，不根据题号推算图片名称。图片与听力使用同一个 R2 公开域名（`NEXT_PUBLIC_AUDIO_BASE_URL`），浏览器直接加载，不经过 Vercel 中转。图片尚未上传时提示加载失败，可点击“重新加载图片”重试，成功上传后无需修改题库或重新部署。

R2 Bucket 根目录下的 `audio/` 和 `pic/` 是同级目录。例如 N2 2024 年 12 月原题 70、71 共用：

```text
audio/202412n2/1.mp3
pic/220241270.jpg
```

对应图片 URL 为 `https://pub-8ac2a059bee9443c839a7e7f2f350e93.r2.dev/pic/220241270.jpg`。共享图片的小题使用同一个阅读抽屉并统一提交；不同图片保留各自映射。图片使用按需加载、加载状态和失败重试，也保留旧的本地 `/imported-media/` 图片兼容。

题目、文章和收藏页中的配图均可点击全屏查看。在预览区域滚动鼠标滚轮，以鼠标位置为中心放大或缩小（适应屏幕的 1–4 倍），按住左键可拖动查看；手机支持双指缩放、单指拖动。拖动限制在图片边界，松开后不会误触关闭。保留缩放按钮和适应屏幕按钮，点击关闭按钮、空白处或按 Esc 返回；聚焦图片区域后，方向键可平移，`+`/`-` 调整缩放，`0` 恢复适应屏幕。

子题独有的 `picture` 与父题配图区分保存为可选 `media.questionImages`，在该小题题干下方、选项前渲染，不影响同一篇文章分组。N3 2014 年 7 月阅读题已按更新资源导入，原题 73 的子题配图使用附件提供的 `pic/320140773-1.jpg`，父题使用 `pic/320140773.jpg`。2014 年 12 月题组保留原来的 `pic/320141273.jpg`，不包含这张 7 月子题配图。

听力末尾共用音频的多道小题使用同一个可拖动抽屉，练习时全部选择后统一提交；组内切题保留播放器和播放进度，离开该组时暂停。答题卡继承该组题型说明，不把缺少说明的小题拆成“练习题”。考试仍在整卷交卷时统一评分。

验证：`node --test scripts/test-reading-images.mjs scripts/test-practice-papers.mjs scripts/test-restore-practice-paper.mjs` 和 `npm run check:bank`。重新导入题库时，阅读题的安全 `pic/` 引用同样允许先导入、后上传图片，其他缺失媒体规则保持原样。

## 加载提示与云备份

练习准备、收藏题加载和学习记录读取使用骨架屏；开始练习及云端操作提供 loading 状态，成功/失败通过可关闭的消息提示。手机端入口仅显示图标，宽屏显示图标与文字。

Cloudflare D1 支持账号密码登录（注册时需确认密码）、手动备份与合并恢复收藏和学习记录，独立于现有答题与暗号功能。需要创建 D1、初始化表，并配置 Vercel 服务端环境变量；完整步骤见 [Cloudflare 云备份配置](docs/cloud-backup.md)。部署读取到完整的三个服务端环境变量后自动启用，无需额外开关；未配置数据库时会明确提示，刷题仍可使用。

## 检查与构建

题库反馈入口位于答题设置，管理员查看页面为 `/feedback`，首次启用需要反馈表及管理员允许名单，详见 [题目反馈配置](docs/question-feedback.md)。可以重复运行 `npm run setup:feedback` 创建新表，不会删除云备份。新反馈表迁移为 [0002-question-feedback.sql](migrations/0002-question-feedback.sql)。

题库图片/音频可使用 `npm run check:resources` 检查引用，或加 `--remote` 检查公开URL；默认限制100个远端资源，详见 [资源检查](docs/resource-check.md)。API 已加入IP/会话突发限流、持久账号限流及实际请求体大小限制；R2直连资源需Cloudflare自定义域名和边缘规则防刷，代码范围及配置见 [请求限流](docs/request-limits.md)。

电脑答题设置可开启/关闭快捷键：1–4选择、Enter提交或继续、左右箭头切题；输入控件、组合输入、弹窗和移动设备保持原交互，大题仍统一提交，考试交卷仍需确认。

```bash
npm run lint
npm run check:bank
npm run build
npm start
```

## GitHub + Vercel 部署

将仓库推送至 GitHub，然后在 Vercel 导入该仓库：

- Framework Preset：Next.js
- Root Directory：项目根目录（`.`）
- Install Command：`npm ci`
- Build Command：`npm run build`
- Output Directory：保留 Next.js 默认值
- Environment Variables：已配置默认 R2 公开音频域名，首页按题型选择“听力”；更换域名可用 `NEXT_PUBLIC_AUDIO_BASE_URL` 覆盖

应用包含服务端题库读取和 API，使用 Vercel 的 Next.js 部署方式。`next.config.ts` 已配置题库 JSON 文件追踪，生产部署包含练习和收藏接口需要的数据。

关联 GitHub 后，推送至生产分支触发生产部署，其他分支或 PR 生成预览部署。不要提交 `.env*`、`.vercel`、`node_modules` 或 `.next`。

题库格式与导入说明见 [src/data/README.md](src/data/README.md)。

## MP3 听力播放

播放器以单行显示播放/暂停图标、进度、时长和 0.75–1.5 倍速，切题时自动暂停，加载失败可重试。音频按当前题目按需直连 Cloudflare R2，不经过 Vercel。

首页选择场次和“听力”即可开始练习或考试。题目继续使用已有音频路径，不预先检查所有远端文件；某题播放时文件缺失或加载失败，再显示错误和重试。上传或覆盖同路径录音后，已开放题目无需重新导入。题型说明在题目或文章上方展示，答题卡仅保留题号与设置入口。设置内可用滑块实时调节题目、文章、选项和解析的字号（14–28px），练习、考试和复习均支持。手机端题目默认 16px，桌面默认 18px，两个尺寸可分别调节。手机答题页固定顶部返回栏和底部答题卡，中间内容独立滚动；阅读抽屉保留拖动与展开/收起，并避开底部答题卡。

R2 Bucket、公开域名、上传凭据、批量上传、题库关联和 Vercel 配置步骤见 [听力部署说明](docs/r2-audio.md)。密钥只用于本地上传，不提交到 GitHub；`npm run upload:audio -- --directory <资源根目录> --dry-run` 可预检目录，`npm run test:audio` 运行音频相关测试。

## 暗号与收藏练习

暗号功能暂不启用，普通答题和收藏练习均可直接进入，不需要暗号或已有 Cookie。

以后需要启用时，将 `src/lib/access-config.server.ts` 的 `PASSPHRASE_REQUIRED` 改为 `true`，提交后重新部署。启用后由服务端校验共享暗号，通过 HttpOnly Cookie 为当前浏览器保留 30 天的验证状态。仓库只保存暗号摘要，明文不会进入前端包。

需要更换暗号时，运行 `node scripts/rotate-activation-code.mjs`，妥善保存终端返回的新码，然后提交摘要文件并重新部署。更换后旧码和旧浏览器验证状态失效；安装依赖时不要运行此命令。

收藏页可以按收藏夹、等级、题型筛选，再点击“练习当前收藏”。练习只包含所选收藏题目，同篇文章仅对本次选中的子题统一提交；本次题目列表固定，期间修改收藏不会重置作答。结算、错题收藏及锁定复习流程与普通练习一致。

手机收藏页默认显示场次、等级、题型、题号与收藏夹摘要，点击后查看题目，支持返回一览；电脑默认左侧滚动选题、右侧查看题目。手机收藏设置提供“摘要列表、完整卡片”两种模式，以及排序、字号和收藏夹管理；完整卡片可连续浏览。电脑固定左侧摘要一览、右侧完整题目，不再显示查看模式选择。练习当前收藏使用带提示的播放图标。电脑弹窗在鼠标点击或键盘触发按钮附近打开，自动避开屏幕边缘；手机维持原有弹窗布局。顶部按钮统一为 44px 高，图标按钮为 44×44px。
